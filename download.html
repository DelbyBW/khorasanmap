Installation

  1. Download the archive and extract it if needed.
  2. Copy the .scs files into Documents\Euro Truck Simulator 2\mod.
  3. Start the game and open Mod Manager in your profile.
  4. Enable the mods and set the load order shown below.
  5. Start a new profile or use a save that is compatible with the map.
